Laptop yang makin lama makin lemot adalah keluhan paling umum pemakai Windows 11. Padahal belum tentu harus beli laptop baru — sering kali penyebabnya adalah hal-hal kecil yang menumpuk di sistem, dan semuanya bisa dibereskan sendiri dalam satu-dua jam. Artikel ini membahas penyebab paling umum dan langkah perbaikan yang benar-benar bekerja, mulai dari yang paling mudah sampai yang paling teknis.

## Kenapa laptop Windows 11 cepat lemot?

Sebelum memperbaiki, kenali dulu biang keladinya. Lima penyebab paling umum:

1. **Startup apps terlalu banyak** — banyak aplikasi jalan otomatis saat Windows menyala, makan RAM dan CPU sejak awal.
2. **Storage hampir penuh** — SSD/HDD yang tinggal sedikit ruang (di bawah 15%) membuat sistem jauh lebih lambat.
3. **Efek visual & animasi** — Windows 11 penuh animasi yang berat untuk laptop spek pas-pasan.
4. **Background apps & proses tersembunyi** — aplikasi berjalan di latar belakang tanpa kamu sadari.
5. **Driver usang atau sistem kotor** — file sementara menumpuk, driver lama, atau update tertunda.

## Langkah 1: Matikan aplikasi startup

Aplikasi startup adalah penyebab nomor satu laptop terasa lambat sejak dinyalakan:

1. Tekan **Ctrl + Shift + Esc** untuk membuka Task Manager.
2. Klik tab **Startup apps**.
3. Urutkan kolom **Startup impact** — fokus pada yang berlabel *High impact*.
4. Klik kanan aplikasi yang tidak penting (Spotify, Discord, updater, dll) → **Disable**.

Panduan lengkapnya ada di artikel [Cara Mematikan Startup Apps di Windows 11](/tech/cara-mematikan-startup-apps-windows-11/). Setelah ini, laptop akan nyala lebih cepat.

## Langkah 2: Bersihkan storage

Storage penuh bikin Windows tersendat. Bersihkan dengan Storage Sense:

1. Buka **Settings** → **System** → **Storage**.
2. Aktifkan **Storage Sense** → klik **Configure Storage Sense or run it now**.
3. Centang opsi pembersihan: file sementara, file recycle bin, download lama.
4. Klik **Clean now**.

Kalau masih penuh, cek aplikasi terbesar: **Settings** → **Apps** → **Installed apps** → urutkan berdasarkan ukuran. Hapus yang tidak dipakai. Detailnya ada di [Cara Membersihkan Storage Windows 11](/tech/cara-membersihkan-storage-windows-11/).

## Langkah 3: Matikan efek visual

Animasi Windows 11 terlihat cantik, tapi berat untuk laptop spek rendah:

1. Tekan **Win + S**, ketik **"Performance Options"**, buka **Adjust the appearance and performance of Windows**.
2. Pilih **Adjust for best performance** — semua efek visual dimatikan.
3. Atau pilih **Custom** dan centang hanya yang kamu butuhkan (misal *Show thumbnails*).

Perubahan langsung terasa, terutama di laptop dengan RAM kecil atau GPU lemah.

## Langkah 4: Matikan background apps

Aplikasi yang berjalan di latar belakang diam-diam makan sumber daya:

1. **Settings** → **Apps** → **Installed apps**.
2. Klik aplikasi yang sering berjalan di background → **Advanced options**.
3. Di bagian **Background app permissions**, pilih **Never**.

Lakukan untuk aplikasi yang tidak perlu notifikasi real-time. Untuk game dan aplikasi penting, biarkan tetap *Always*.

## Langkah 5: Update driver & Windows

Driver usang sering bikin sistem lambat dan tidak stabil:

1. **Settings** → **Windows Update** → **Check for updates** — install semua update.
2. Buka **Device Manager** (klik kanan Start) → klik kanan perangkat → **Update driver** → **Search automatically**.
3. Prioritas: driver **chipset**, **GPU**, dan **storage controller**.

## Langkah 6: Pertimbangkan upgrade (opsional tapi paling efektif)

Kalau semua langkah di atas sudah dilakukan dan laptop masih lemot, kemungkinan masalahnya di hardware:

- **Upgrade ke SSD** — kalau laptop masih pakai HDD, ganti ke SSD NVMe adalah upgrade paling berdampak. Booting dan buka aplikasi jadi berkali-kali lebih cepat. Cek dulu [kesehatan SSD](/tech/cara-mengecek-kesehatan-ssd-di-windows/) sebelum upgrade.
- **Tambah RAM** — kalau pemakaian RAM sering di atas 90%, tambah RAM. Cek dulu [cara cek RAM](/tech/cara-mengecek-ram-laptop-di-windows/) untuk tahu tipe dan slot yang tersedia.
- **Cek suhu** — laptop yang panas terus-terusan akan menurunkan performa otomatis (throttling). Pastikan ventilasi bersih dan pakai cooling pad.

## Tips tambahan

- **Restart rutin** — jangan cuma sleep. Restart minimal 3 hari sekali membersihkan proses yang menumpuk.
- **Jangan install terlalu banyak antivirus** — cukup Windows Defender bawaan + satu antivirus tambahan kalau perlu.
- **Kurangi tab browser** — browser adalah pemakan RAM terbesar. Tutup tab yang tidak dipakai atau pakai ekstensi penghemat RAM.
- **Jangan penuhi desktop** — file di desktop ikut dimuat saat boot. Simpan di folder lain.

## Kesimpulan

Laptop lemot di Windows 11 biasanya bukan karena laptopnya sudah "tua", tapi karena sistemnya tidak dirawat. Mulai dari mematikan startup apps, membersihkan storage, mematikan efek visual, sampai update driver — semuanya bisa dilakukan gratis tanpa install ulang. Kalau masih kurang, upgrade SSD dan RAM adalah investasi yang paling masuk akal dibanding beli laptop baru.
