Tombol keyboard mechanical tiba-tiba mengetik dua huruf sekaligus (misal: menekan "a" tapi muncul "aa") — ini disebut **double input** atau **chattering**. Gangguan ini mengganggu mengetik dan bermain game, tapi biasanya bisa diperbaiki sendiri di rumah.

## Penyebab umum double input

1. **Debu/kotoran di switch** — partikel halus mengganggu kontak logam.
2. **Oksidasi kontak** — switch lama atau terpapar kelembapan.
3. **Pegas switch ngeles/aus** — tidak mendorong stem kembali cukup cepat.
4. **Keycap longgar/tilt** — menekan switch tidak merata.
5. **Firmware/software** — debounce time terlalu pendek (jarang, tapi bisa jadi).

## Cara mengatasi (urut dari paling mudah)

### 1. Bersihkan switch dengan udara bertekanan (compressed air)
- Cabut keyboard dari PC.
- Balikkan keyboard, ketuk pelan agar kotoran keluar.
- Semprotkan *compressed air* ke sela-sela switch bermasalah (sudut 45°, jarak ±5 cm).
- Tes kembali.

### 2. Gunakan *contact cleaner* (opsional, kalau poin 1 gagal)
- Beli *contact cleaner* elektronik (misal: CRC QD Electronic Cleaner).
- Semprotkan sedikit ke celah switch (tanpa melepas keycap dulu).
- Tekan tombol bermasalah berulang kali ±20x agar cairan meresap.
- Biarkan kering 10–15 menit sebelum dipakai.

> ⚠️ **Jangan** pakai WD-40, alkohol tinggi, atau cairan berminyak — bisa merusak plastik dan pegas switch.

### 3. Lepas keycap & bersihkan lebih dalam (butuh keycap puller)
- Cabut keycap tombol bermasalah + tetangganya (biar mudah akses).
- Semprot *compressed air* + *contact cleaner* langsung ke stem switch.
- Tekan stem manual (pakai ujung pensil) berkali-kali.
- Pasang keycap, tes.

### 4. Cek *debounce time* di software keyboard (kalau ada)
Beberapa keyboard (Keychron, Wooting, dll) punya pengaturan *debounce time* di software resminya. Naikkan nilainya (misal dari 5 ms → 10–15 ms) untuk mengabaikan chattering ringan.

### 5. Ganti switch (hanya keyboard **hot-swap**)
Jika keyboard mendukung hot-swap:
- Cabut switch bermasalah pakai *switch puller*.
- Pasang switch baru (bisa beli switch per biji).
- Tes.

> Jika keyboard **bukan hot-swap** (switch disolder), solusi ini butuh soldering. Pertimbangkan bawa ke teknisi atau ganti keyboard kalau banyak switch bermasalah.

## Pencegahan

| Kebiasaan | Manfaat |
|---|---|
| Tutup keyboard saat tidak dipakai (pakai cover/kain) | Mencegah debu masuk switch |
| Bersihkan rutin tiap 1–2 bulan (kuas + compressed air) | Mengurangi risiko chattering |
| Hindari makan/minum di atas keyboard | Cegah percikan cairan & remah |

## Kapan harus ganti keyboard?

- >3 switch chattering bersamaan (biaya perbaikan > keyboard baru entry-level).
- Keyboard sudah >5 tahun & tidak hot-swap.
- Chattering kembali berulang setelah dibersihkan 2–3 kali.

## Kesimpulan

Double input kebanyakan disebabkan debu/oksidasi di switch. **Bersihkan dengan compressed air + contact cleaner + tekan tombol berulang** menyelesaikan 80% kasus. Kalau keyboard hot-swap, ganti switch bermasalah saja. Kalau tidak, bersihkan maksimal — kalau tetap bermasalah, mungkin waktunya upgrade.
