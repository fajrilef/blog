Pernah mengetik "halo" tapi yang muncul "hhaalloo"? Itu namanya **double input** — satu kali tekan tombol, tapi terdaftar dua karakter. Masalah ini paling sering muncul di keyboard mechanical yang sudah dipakai lama, dan kabar baiknya, sebagian besar kasus bisa diperbaiki sendiri tanpa beli keyboard baru.

## Penyebab umum double input

Sebelum memperbaiki, kenali dulu penyebabnya. Ada empat penyebab paling sering:

1. **Debu atau kotoran di dalam switch** — partikel kecil mengganggu kontak logam, membuat switch terdaftar dua kali saat dilepas.
2. **Switch sudah aus (worn out)** — setelah jutaan penekanan, pegas dan kontak switch kehilangan presisi.
3. **Debounce time terlalu rendah** — setting di firmware keyboard atau software terlalu sensitif, sehingga getaran kecil dihitung sebagai penekanan baru.
4. **Masalah solder (cold joint)** — koneksi solder longgar di PCB, biasanya setelah keyboard terjatuh atau terkena benturan.

## Cara memperbaiki double input

### 1. Bersihkan switch yang bermasalah

Ini langkah pertama dan paling sering berhasil:

1. Matikan keyboard dan cabut kabelnya.
2. Lepas keycap tombol yang bermasalah dengan **keycap puller** — tarik lurus ke atas.
3. Semprot switch dengan **compressed air** atau blower mini untuk membuang debu.
4. Teteskan **contact cleaner khusus elektronik** (bukan air biasa!) ke dalam switch, tekan-tekan tombolnya 10-15 kali agar cairan merata.
5. Biarkan kering 10-15 menit, pasang keycap kembali, tes mengetik.

> **Catatan:** jangan pakai alkohol isopropil terlalu banyak atau WD-40 — bisa merusak pelumas di dalam switch.

### 2. Cek setting debounce di software keyboard

Kalau keyboardmu punya software resmi (seperti VIA, QMK Toolbox, atau software merek):

1. Buka software keyboard.
2. Cari pengaturan **debounce time** (biasanya di menu Settings/Advanced).
3. Naikkan dari default (misal 2ms) ke **5-8ms**.
4. Simpan dan tes kembali.

Debounce yang terlalu rendah membuat keyboard membaca getaran ganda saat pegas kembali — menaikkannya sedikit biasanya langsung menghilangkan double input.

### 3. Tukar switch (kalau keyboard hot-swap)

Kalau pembersihan dan setting debounce tidak berhasil, kemungkinan switch-nya memang sudah aus. Di keyboard **hot-swap**, solusinya mudah:

1. Cabut switch bermasalah dengan **switch puller**.
2. Tukar dengan switch dari tombol yang jarang dipakai (misalnya Scroll Lock atau Pause).
3. Pasang switch cadangan di posisi tombol bermasalah.
4. Tes — kalau double input pindah ke tombol baru, berarti switch-nya yang rusak, bukan PCB.

Ini keuntungan utama keyboard hot-swap: perbaikan tanpa solder, cukup cabut dan pasang.

### 4. Perbaikan solder (terakhir, butuh keahlian)

Kalau keyboardmu **bukan hot-swap** dan masalah tetap ada setelah semua langkah di atas, kemungkinan besar solder di PCB longgar. Perbaikannya butuh solder dan pengalaman — kalau belum pernah solder, lebih aman bawa ke tukang servis keyboard atau pertimbangkan ganti keyboard.

## Kapan harus ganti keyboard?

Ganti keyboard kalau:

- Banyak tombol (lebih dari 3-4) yang double input.
- Masalah muncul di tombol yang sering dipakai (WASD, spasi, enter) dan tidak bisa ditukar.
- Keyboard sudah dipakai sangat lama dan biaya perbaikan mendekati harga baru.

## Kesimpulan

Double input biasanya bisa diatasi dengan pembersihan switch, menaikkan debounce time, atau menukar switch di keyboard hot-swap. Mulai dari langkah termudah dan termurah, dan jangan langsung menyalahkan keyboard — sering kali masalahnya hanya debu yang menumpuk di dalam switch.
